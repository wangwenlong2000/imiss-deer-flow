判断目标是否**连续**5分钟出现在禁停区，核心在于从"单帧检测"升级为"跨帧时序追踪"。下面给出完整方案：

---

## 一、判定逻辑框架

| 判定维度 | 关键要点 |
|---------|---------|
| **时间连续性** | 目标ID在相邻帧之间不断裂（同一目标不被误拆或误合并） |
| **空间一致性** | 目标始终位于禁停区的地理围栏内 |
| **有效停留时长** | 累计 ≥ 300秒（可设容差 ±N 秒） |
| **中断判定** | 目标消失超过容差阈值后重新出现 → 视为中断，时间重置 |

---

## 二、具体实施步骤

### 第1步：获取带时间戳的轨迹数据

通过视频分析工具对禁停区域进行持续检测/追踪，输出每帧中目标的：

- **唯一目标ID**（track ID）
- **中心坐标**（判断是否在禁停区内）
- **时间戳**（精确到秒）
- **置信度**（过滤低质量检测）

### 第2步：计算连续停留时长

```
伪代码逻辑：
1. 按目标ID分组所有检测记录
2. 对每个目标ID的记录按时间戳排序
3. 遍历记录，检查相邻帧的时间间隔 Δt：
   - 如果 Δt ≤ 容差阈值（如 3~5 秒）→ 属于同一段连续停留
   - 如果 Δt > 容差阈值 → 前一段结束，新的一段开始
4. 累加每段的有效停留总时长
5. 如果任一段 ≥ 300秒 → 判定为"连续5分钟违规"
```

### 第3步：容差设计

为避免短暂信号丢失导致误判，建议设置：

- **最大允许中断时间**：3~5秒（即目标短暂被遮挡后恢复仍可算作连续）
- **最低检测频率**：至少每秒1帧以上
- **置信度下限**：剔除置信度过低的误检
