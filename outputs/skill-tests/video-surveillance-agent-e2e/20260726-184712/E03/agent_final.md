## 视频对象统计结果

基于对 **Trafic-30s.mp4** 的完整30秒视频分析（每2秒采样1帧，共15帧），通过YOLOv8目标检测+跨帧跟踪算法去重后，统计结果如下：

| 类别 | 数量 | 说明 |
|------|------|------|
| 🚗 小汽车 (car) | **7辆** | 包含静止与移动状态 |
| 🚌 公交车 (bus) | **2辆** | 其中1辆行驶中，1辆静止 |
| 🚙 合计车辆 | **9辆** | |
| 🚶 行人 (person) | **1人** | 出现在10~16秒区间 |

**关键发现：**

- **车辆**在视频前段（0-8秒）最为密集，最多同时出现11个目标；后期逐渐减少至2辆
- **行人**仅在10~16秒时段出现，出现在画面右侧区域（约x=936~1055像素位置），持续约6秒
- 所有跟踪轨迹均经过跨帧ID关联，已排除同一目标的重复计数

> ⚠️ **注意**：由于采用2秒间隔采样，部分快速通过的短时目标可能未被捕捉到。如需更精确的全量统计，建议使用更小采样间隔或全量帧检测。
