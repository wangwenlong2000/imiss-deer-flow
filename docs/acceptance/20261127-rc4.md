## 范围

本轮范围为 Linux amd64、MySQL 8.0.39、外部聊天模型 API、固定兼容工具沙箱的 `basic-online-api` 单机版。包含账号与隔离、真实问答、CSV 工具计算及文件产物、停写备份和同机独立目录/Compose 恢复。不同物理机器迁移、原地升级/回退、ES、GPU、视频、遥感、NAS 及全部 Skill 业务场景不在本结论内。

本版合并已真实复验的上传路径特征修复、语义问答验收要求修复，以及留样工具的绝对 URL 与 Gateway 操作资源提示合同修复。文件下载仍经授权代理，Gateway 身份仍由服务端 IAM 验证；未伪造身份、线程、admission 或业务成功结果。

## 已知限制与证据边界

- 历史短 CSV 仍存在纯内容 `domain` 误报（相似度 0.138258、low），可能阻止其他无害 CSV 上传。本轮没有降低阈值、增加验收样本白名单或改变模型/策略矩阵。当前基础验收 CSV 的物理路径污染已修复。
- 119 个 Skill 的声明及依赖静态检查不等于全部业务场景通过，所需外部服务和资产另行验收。
- 工具沙箱为固定兼容资产，不声称由本版源码重新清洁构建或已经全面审计历史层。前端为保留 builder 输入及编译产物对应核验，不冒称独立重编译。
- 既有账号和文件恢复，与恢复站点新建测试账号/Gateway 业务分开验证；新业务成功不替代原数据恢复。
- 本轮恢复在同一物理机器的独立目录、端口和 Compose 项目执行，不等于不同物理机器迁移验收。
- 发布清单的 `acceptance.delivery_accepted=false` 表示完整性工具不自行授予业务或跨机器验收；实际分项业务结论以本记录和独立脱敏证据为准。
