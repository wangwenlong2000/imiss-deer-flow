## 具体修复

| 问题 | 改法与可验证行为 |
| --- | --- |
| 澄清后仍保留空场景 | 区分“已知业务补参数”和“首次澄清业务”。后者将真实原问题、当前回答及实际选中选项合并，重新执行一次结构化识别，更新场景和确认后的任务原文；已知业务续接保留快速路径。 |
| 历史附件和任务背景丢失 | 上传状态同时保留仍存在的新旧文件；文件全部删除时清空失效元数据。识别器补充最近六条真实用户原文和受限文件元数据，帮助切换话题后回访早期文件，不把旧模型生成的总结当用户证据。 |
| 合法跨句引文被否决 | 支持引文数组及省略号分隔片段，但每一段均须能在输入中找到；包含任何无来源片段仍拒绝。结构化修复只回传校验原因，最多再识别一次。 |
| 道路/网络统计被归入表格年鉴 | 收窄场景说明并补充语义对照：业务对象决定场景，CSV、均值、排名、输出表格属于处理或交付方式。未添加关键词硬路由。 |
| 轨迹末段停留漏算 | 在扫描到轨迹末尾时结算已满足时长的停留，包含恰好 20 分钟；两份共用实现同步修改。汇总保留停留次数为零的用户。冻结九点数据直接得到 A=2、B=0，无需模型现场改技能代码。 |
| 固定阈值检测拒绝五个数据点 | 仅固定阈值检测的默认最少点数改为 1；统计型检测仍保留默认 8 点，用户显式指定的最少点数仍生效。修正默认输出目录，避免写入只读数据目录。 |
| 输出封装反复类型错误 | 在真正的工具 schema 边界接收数组或 JSON 数组字符串，并校验、去重路径；缺少实际结果和附件的空封装不再假成功。原先代码 AST 任务的字符串参数可成功封装。 |
| 模型跳过计算、直接给数值 | 利用已有意图调用标记是否需要计算。终结回答前检查本轮执行工具证据，旧轮工具结果不能充数；缺失时只纠正一次，有 bash 时要求该纠错请求调用 bash，再失败则明确无法核验。没有固定增加一轮裁判 LLM。 |
| CSV 漏指标、精度不满足要求 | 意图同时记录明确要求输出 CSV 时的指标清单；`present_files` 检查真实文件列、指标到列名的映射及指定小数位数，返回少量已验证文件事实。接收校验对象、数组及对应 JSON 字符串，避免额外的参数类型循环；不要求把英文列名重命名为指标标签。 |
| 排队、上传导致重载或 502 | 显式设后台任务并发为 2，允许环境变量调整；关闭图服务热重载，网关用绝对路径排除运行数据和虚拟环境目录；Nginx 动态解析后端容器地址。上传合成 `.py` 后 PID 不变、连续健康检查通过。 |
| 仅上传文件也耗尽沙箱端口 | 本地共享目录模式上传时直接保存文件，到实际执行才申请沙箱；远程模式继续保留同步。启动命令日志遮蔽环境变量值，实际运行参数保持不变。 |

主要实现位于 `backend/packages/harness/deerflow/routing/intent/structured.py`、`agents/middlewares/intent_recognition_middleware.py`、新增的 `agents/middlewares/computation_guard_middleware.py`、`tools/builtins/present_file_tool.py`、`tools/builtins/invoke_skill_tool.py`，以及对应技能脚本和 Docker/Nginx 配置。后端 README、CLAUDE 文档已同步。

## 尚未完全解决

计算门禁证明存在本轮执行证据，CSV 校验证明声明的列与格式存在；二者都不能自动证明全部数值、比较关系、因果解释正确。本轮道路回答仍额外使用“典型高峰拥堵”“符合早高峰规律”等定性判断，仅凭这点合成数据不足以支持，不能标为全文完全正确。

网络与年鉴任务仍有工具和交付重试，个别请求比旧版慢。调整温度与语义说明也不能保证模糊请求永不误判。当前规则检查和语义识别的责任不同，不应通过新增关键词硬分流掩盖这些问题。

[本地移动端适配回放](full-flow-fixes-eval-20261022/refined-mobile-adapter.json)保留七个最终回答和一次澄清，六个业务回合有规划段；澄清后计算回合没有独立规划展示段，尚需单独完善这一展示路径。未向 OneCityAgent 实际发送任务，未验证浏览器流式展示，也未验证本地部署后的模型时延。所有中间失败与重试批次均保留，不用最好一次覆盖它们。
