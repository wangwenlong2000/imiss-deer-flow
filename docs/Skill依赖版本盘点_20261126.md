## 4. 已发现的版本差异和缺项

| 对象 | 声明 / 所需条件 | 实测基线 / 影响 |
| --- | --- | --- |
| 街景 location-matcher | Python ≥3.11 | 沙箱为 3.10.12，不满足声明；需统一运行环境或验证并调整声明 |
| 街景 ES Python 客户端 | `elasticsearch>=8,<9` | 沙箱 9.5.1，声明不符；ES服务端9.3.3与客户端是两个独立版本 |
| 道路 RAG | `sentence-transformers==5.4.1` | 沙箱 6.0.1，声明不符 |
| 道路 RAG | `PyMuPDF==1.27.2.3` | 沙箱 1.26.6，声明不符 |
| 微信抓取 | Node锁文件 Playwright / playwright-core 1.59.1，且需要匹配的浏览器资产 | 已核对全局目录与挂载的微信Skill本地node_modules，未检出这两个Node包；系统Chromium存在不能代替Playwright包 |
| JS / C++代码解析 | esprima、tree-sitter、tree-sitter-cpp（按语言需要） | 沙箱Python元数据未检出；不影响仅用标准库解析Python的分支 |
| 代码切分适配 | langchain-text-splitters / llama-index-core，部分语言后端按分支需要 | 沙箱元数据未检出；部分调用存在全文chunk回退，不能等同正常切分 |
| OpenGrep | 下载脚本默认 v1.21.0；运行器需可执行二进制和规则资产 | PATH未检出，但Skill自带二进制存在；现网挂载文件mode=0664、不可执行，且skills只读挂载；需在发布资产中修复执行位，默认下载值不能当成实测版本 |
| 代码DAG迁移 | 部分入口仍引用旧 `skills/public` 路径 | 需核对路径兼容；依赖齐全也不代表入口可以运行 |
| OpenCV | opencv-python / opencv-python-headless共享cv2模块 | 镜像同时存在4.12.0.88和5.0.0.93，需按实际导入和视频分支验证；不能把两份包视为两套独立cv2实现 |
| 运行期安装 | 部分数据、道路、微信工具会在缺依赖时自动安装 | 未锁版本、依赖网络和写权限；本次没有触发安装 |
