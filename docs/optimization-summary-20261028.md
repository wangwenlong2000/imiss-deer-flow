# 近期优化内容汇总（截至2026-10-28）

本轮工作从“减少意图识别调用”扩展到“提高全过程可靠性”。当前模型固定为 **Qwen3.6-35B-A3B**；普通业务意图识别通常一次结构化调用，业务执行沿用工具和合规检查。最近24轮回归的核心任务符合预期，仍有3处扩展说明偏差，不能视为全部文字正确。

## 一、模型与业务范围

- 固定使用Qwen3.6-35B-A3B，满足项目选用可本地部署模型的要求。当前实测调用DashScope，本地权重部署的性能和验收尚未验证。
- 场景收敛到10类：网络流量、电话网络、政策法规、时空轨迹、街景图像、遥感图像、视频监控、程序片段、道路交通、表格年鉴。
- 移除火灾等6类演示场景；技能过滤也核对实际注册表，避免旧会话重新引入已移除场景。
- 按阶段控制思考：意图识别、对话关系判断等辅助任务关闭；业务默认开启，用户显式关闭时尊重该设置；子任务继承父任务开关，不再一律关闭。

## 二、意图识别：减少调用，同时保留语义判断

| 优化项 | 以前的问题 | 现在的做法 |
| --- | --- | --- |
| 合并识别流程 | 切分、改写、分类、抽参和规划分散调用 | 同一次结构化调用输出任务、场景、参数、原文证据和执行规划，减少重复上下文和往返 |
| 取消关键词硬筛选 | 模糊表达或未命中关键词时，正确场景根本无法进入候选 | 十类场景全部参与语义判断，用处理对象、业务目标和场景边界区分 |
| 处理歧义 | 将泛“流量”、背景词或输出表格要求强行归入某领域 | 真正缺领域对象时保留未知并具体澄清；缺日期、文件等执行参数时，在已知领域内核验补齐 |
| 保护多目标 | 引文格式失误可能丢失整组任务，降级后只执行一部分 | 引文支持真实片段及空白归一，保留来源验证；无法得到有效完整结果时明确失败，避免静默执行残缺任务 |
| 限制额外调用 | 校验失败后重复启动多步识别链 | 正常一次，结构校验最多修复一次；简单控制请求可走零模型路径，多轮关系判断可能额外调用 |

没有引入embedding、reranker或新的分类模型。场景理解仍由固定Qwen完成；本地代码负责格式、白名单、引文来源和约束一致性校验。模型自评置信度未经校准，不作为保证准确的阈值。

## 三、多轮对话：复用对象，更新本轮要求

- 区分延续、补参、换题、取消子任务和回访历史文件，避免每次都重走完整业务识别。
- 已知业务补参数可以快速续接；从未知领域澄清到明确业务时，需要重新确定场景。
- 传递受限的真实用户历史和仍存在的附件元数据，支持换题后回到早期文件；不把模型生成的总结当用户原文。
- 统一当前轮约束：是否计算、能否调用工具、文件类型、指标、精度和缺失值标记由识别、续接、执行、交付共享。
- 当前明确指标与产出替换对应历史需求；复用文件不自动继承旧导出。明确保留全部、只改格式等指令才继承相应约束。
- “只解释、不执行、不导出”会清除旧计算/交付要求；“取消代码，只算GDP”不会继续执行被取消任务。

## 四、全过程：让计算、文件和最终状态相互对应

| 优化项 | 具体变化 |
| --- | --- |
| 实际计算证据 | 需要计算的任务必须有本轮工具执行证据，不能仅凭模型口算或复述历史结果交付 |
| 思考与工具兼容 | 纠错使用auto工具选择，修复思考模式强制指定工具导致的400；仍检查实际执行结果 |
| 有界纠错 | 缺计算或交付证据时最多一次终结纠错；重复交付错误和循环停止明确标记失败，不包装成成功 |
| 文件登记 | 核验实际文件、本轮来源、运行标识和SHA-256；旧文件、修改后文件不能冒充本轮已核验交付 |
| 遗漏展示 | 对本轮实际新建/修改且符合要求的文件，遗漏登记时最多安排一次正常展示，沿用权限、合规与格式检查 |
| 重复成功展示 | 已完成全部要求且相同文件成功展示两次时，让下一轮直接给最终答复，避免继续循环 |
| CSV正确性 | 严格引号、非空唯一表头、固定行宽、逐指标精度和明确NA标记；支持合法空表和引号内换行 |
| 分文件交付 | 明细可无汇总指标；最终对全部本轮有效文件求指标并集，缺项仍不允许完成 |
| 参数反馈 | 工具缺少description等字段时明确指出JSON缺项，减少无效重试 |

## 五、业务技能、运行环境和回答质量

- **轨迹**：修复末段停留和恰好达到时长边界的结算，保留零次用户；脚本直接生成事件CSV，原JSONL及算法计数保留，空结果也有表头。
- **异常检测**：固定阈值检测支持小样本；统计型检测保留其最小样本要求，输出写到可写目录。
- **上传稳定性**：开发服务热重载排除用户上传/运行目录，避免上传Python文件触发重载并影响其他上传。
- **合规误报**：在适配层区分算术、语法/格式校验与访问授权校验，修复正常AST导出误拦；冻结核心及其他风险规则保留。
- **明确数值比较**：对已核验CSV中的实体、指标和比较关系做Decimal核对，明确矛盾进入原有一次纠错；含糊关系按未知处理，不增加LLM裁判调用。
- **解释依据**：至多20行小表展示完整输入，大表标明预览不完整；解释使用已观测明细，不由均值编造原始记录。

尝试过额外LLM核对，但重复测试仍漏错，思考核对还增加十几秒延迟，因此最终撤回。当前数值检查有明确覆盖范围，不能证明任意文字结论正确。

## 八、仍需改进的内容

最近逐句核对发现3处未解决的扩展说明偏差：道路车速波动比较无依据、生成器表达式被叫成列表推导式、除零分析中额外的底层实现解释不严谨。核心计算和文件正确不等于这些文字正确。

此外，模糊领域、范围外请求和多个相近场景仍需更大独立标注集验证；街景、遥感、视频等能力尚未由这24轮全面验收；本地模型部署性能和OneCityAgent真实端到端联调也尚未完成。

后续重点是让最终断言绑定可引用证据，减少无依据扩展结论，并使用独立新题验证，而非增加关键词补丁或重复模型审查。此项尚未实现。
