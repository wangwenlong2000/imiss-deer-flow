# 十场景意图识别与全过程可靠性优化（2026-10-28）

本次将原多次调用的意图理解合并为通常一次结构化语义识别，并修复多轮约束、实际计算、文件交付及最终状态之间的不一致。模型固定Qwen3.6-35B-A3B，保留十类业务及OneCityAgent规划分段协议。

## 优化内容

- 一次输出任务、场景、参数、原文证据和规划，十类完整参与语义判断，取消关键词候选硬筛选；结构输出有界修复，失败不静默执行部分目标。
- 区分追问、补参、换题和取消；携带受限的真实历史与附件元数据，复用数据时不继承已取消的计算或导出要求。
- 意图和辅助判断关闭思考，业务默认开启并支持显式关闭，子任务继承父任务设置；修复Qwen关闭思考开关未正确覆盖的问题。
- 计算任务核验本轮工具证据，交付记录来源、运行标识、哈希和指标映射；分文件检查格式，最终检查全局指标并集。
- 修复思考模式强制工具选择导致的400、文件漏展示、重复展示循环、NA/精度误判及错误占位被标为完成。
- 修复轨迹末段与时长边界，保留零次用户，直接导出事件CSV和合法空明细；固定阈值检测支持小样本。
- 对已核验CSV的明确实体/指标比较作本地Decimal核对；普通数值/语法校验不再误触未授权导出规则；不增加LLM裁判调用。
- 小表提供完整输入预览，大表明确标识不完整；排除上传目录的开发热重载，避免上传Python中断其他请求。

## 模型配置

config.example.yaml仅启用Qwen3.6-35B-A3B。复制为本地config.yaml后，在本机环境配置QWEN_BASE_URL和QWEN_API_KEY；其他存储、沙箱等设置按部署环境填写。不要提交填有凭证的配置或.env。

本地兼容服务需使用相同模型别名，并按实际服务核对思考参数；模型工厂支持enable_thinking和chat_template_kwargs.enable_thinking关闭路径。当前实测使用DashScope，本地权重部署的性能及兼容性尚未验收。

## 复现

在已安装后端依赖的环境中，从backend目录执行无需模型接口的重点回归：

```bash
uv run pytest tests/test_structured_intent.py tests/test_eval_intent_recognition.py tests/test_full_flow_regressions.py tests/test_turn_contract_regressions.py tests/test_remaining_quality_regressions.py -q
```

子任务执行器测试单独运行，避免其现有模块级mock污染其他测试：

```bash
uv run pytest tests/test_subagent_executor.py -q
```

真实服务测试需要先配置模型和运行服务，会产生模型调用费用。脚本只提交合成数据，不向OneCityAgent发送任务。从仓库根目录顺序运行，输出目录需尚不存在：

```bash
python docs/full-flow-thinking-eval-20261027/run_full_flow.py --recursion-limit 1000 --output-run github-recheck
python docs/full-flow-service-eval-20261022/run_full_flow.py --recursion-limit 1000 --output-run github-recheck
```

两批应分别完成后释放其测试专属沙箱再运行下一批，避免资源占满影响结果。需要识别阶段的独立评测时，可在后端环境执行scripts/eval_intent_recognition.py并使用scripts下冻结合成题。
