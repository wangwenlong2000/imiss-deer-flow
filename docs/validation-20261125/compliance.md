# 合规专项回归与处置验收记录

2026-11-25 对合并后的 OneCityAgent / DeerFlow 源码开展十类违规全量引擎回归、30 条新增合成样例及上传和回答链路的专项检查。原始十份标注文件共 2172 条，严格标签集合准确率为 **96.18%（2089/2172）**，宏平均 F1 为 **96.65%**，各类原有正标签均被检出。合规与上传回归共 **731 项通过、1 项按既有条件跳过**。

## 数据与指标口径

2172 条数据来自仓库内 `合规检测/合规评测全部十类违规类型数据/` 的十份 JSONL。其中原标注缺少闸门的 122 条按已有评测约定使用 InputGate，预测逐条保留 `gate_inferred`。数据已用于历史规则开发，本次成绩属于开发回归。30 条新增样例也用于本次问题定位和复测，属于开发回归，均保留原始标签。

引擎运行了真实注册表、检测器路由、规则和已交付 TF-IDF/kNN 模型、意图处理及处置矩阵。本次离线评测未传入业务模型名称，因此第 6/7 类可选外部 LLM 边界复核没有执行。全部 2172 条与新增 30 条扫描完成，检测器异常和未完成数量均为零。该成绩覆盖离线检测链路，线上模型业务成绩由并发测试材料记录。

原数据每行只有一个 `final_violation_type`，引擎可同时发现多类风险。严格准确率要求预测类型集合与原单标签完全相等。逐类型 TP/FP/FN 按 one-vs-rest 计算，表中的 FP 表示超出原单标签的额外命中，需要结合原文逐类确认。83 条差异记录全部来自原有阳性样本，共有 88 个额外命中；原有 830 条 `none` 样本全部保持无命中。完整复核清单已保留。

## 本次发现与整改

| 问题 | 改动与复测 |
| --- | --- |
| 超限重复文本使 Gateway 阻塞 | 已知归一化未完成单元在调用检测器前跳过，保留拒绝与审计。TF-IDF 结构特征的路径箭头正则由逐后缀回溯改为从 token 起点匹配，原 2172 条内容的该布尔特征逐条一致。 |
| 空白、丢失或不可读的提取文本曾被静默跳过并视为通过 | 上传归一化保留未完成单元，区分空文本、不可读、非法 UTF-8 和格式不支持。引擎执行未完成拒绝并记录审计，上传撤回新文件或恢复同名旧文件。 |
| 一个检测器异常后，其他检测器无命中时可能显示通过 | 继续运行其他检测器收集结果，并将整体检查标记为未完成。InputGate、ContextGate、OutputGate 使用现有未完成处置，保留异常和审计。 |
| OneCity 上传代理将 Gateway 的 `success=false` 转为 `code=0` | 代理现在返回 HTTP 422 / code 422、空附件列表、上游拒绝原因及 `compliance.checks`。成功上传同样透传检查结果。 |
| 纯文本、附件检查与页面缺少可对应的检测记录 | 上传返回检查状态、动作、依据、审计编号和 `scan_complete`。完整无风险上传也留有审计记录，未完成上传明确标识检查未完成。 |
| 内部资料包含供应商底价或成本预算漏检 | 扩充受限财务细节识别，同时检查公开培训、已删除和明确不包含的对照样例。新增样例初测的 1 个漏报已修复。 |
| `写明申请人` 中的通用角色被识别为人名 | 姓名实体统一排除通用角色词，保留真实姓名和手机号关联检测。原数据 `policy-20260720-0816` 的误报已修复，原有正例召回保持不变。 |
| FP 明细只检查第一命中类型，遗漏二级命中 | 明细改为逐类型集合比较，额外命中与漏报均有样本编号和原始行号。 |
| 历史测试仍期望未知业务权限放行，流审计仍写旧模式 | 测试改为当前矩阵的未知 domain 拒绝、缺乏可信角色校验拒绝。首方快照传输测试检查 SSE、持久消息和 raw_messages 均为处置后的内容，审计与返回元数据统一为 `buffered_snapshot`。 |

## 专项链路覆盖

| 场景 | 正常、违规与边界检查 | 预期处置和证据 |
| --- | --- | --- |
| 附件文本提取 | 可读文本、提取失败、空白 Markdown、非法编码、丢失文件、同名覆盖 | 接受完整文本并留痕；提取失败返回拒绝原因和审计编号，新文件撤回，同名原件及原 Markdown 恢复。见 `test_compliance_operational_cases.py`。 |
| 长文本检查 | 文件超过 200000 字节、工具及模型输出超过 200000 字符 | 明确扫描未完成并拒绝，保留 `truncated` 和审计。扫描上限按字节/字符定义，CSV 可用行数随行宽变化。 |
| 工具返回 | 多个文本块、正常结果、后续文本块含底线违规、超长文本 | 所有可见文本块参与检测，违规内容在进入下一轮模型上下文前处置。 |
| 多段回答 | 一个 ModelResponse 包含多个 AIMessage、后段违规、单消息多个文本块、持久化与 SSE | 每段回答均检查，正常段保留，违规段改为安全结果；快照与最终状态含合规元数据，重放保持处置结果。 |
| 权限无法确认 | 通用角色词、未知使用场景、未经 IAM 验证的角色、可信本人上下文 | 未知 domain 权限拒绝；矩阵要求角色校验时核对可信上游证明；其他类型按配置的未知场景告警/人工复核处理。 |
| 任务结束 | InputGate 拒绝、OutputGate 处置、上传未完成 | InputGate 拒绝经真实图跳转结束，并验证模型未执行。OutputGate 保留处置后的最终消息。上传失败不进入附件列表，页面显示具体原因与检测记录。 |

上传和文件回撤检查使用隔离目录与实际 Gateway 上传函数。OneCity 代理检查使用临时 SQLite 账号目录和实际 Flask 路由。回答与任务结束检查使用确定性模型替身及真实 LangGraph/中间件。真实浏览器中的操作和实际模型任务由本次联合验收另行记录。

已知超限附件的 210000 个重复字符测试确认检测器零调用，并在 1 秒内返回拒绝。未超过扫描上限的 199000 字符重复内容使用真实引擎验证，在独立子进程 10 秒硬超时内完成，内部断言耗时少于 8 秒。引擎预算目前在单检测器返回后检查，单次规则/模型检测无法被该预算抢占，因此接近扫描上限的可读内容仍可能占用数秒。该限制保留在本次资源与超时验收中。

`make compliance-assets` 的安装路径现会先核对交付提取器的原始 SHA256，复制交付并记录上游 `SHA256SUMS`，随后重新应用唯一已审查的路径箭头补丁。输出文件必须与本次验证的 `8410fe7ec2cf739cae89d8bc060d9e9a2a9d4e2bcb96f85847b836f9555ed24c` 摘要一致。上游文件、补丁定位或输出摘要变化时安装明确报错并要求审查。安装回归使用临时合成交付包，覆盖正常 CLI 安装、重复安装幂等、原始摘要保留和上游不匹配拒绝，安装专项 5 项和现有 vendor 完整性 1 项共 6 项通过。实际运行中的 vendor 和模型文件保持已验证字节。

## 新增样例与剩余复核

新增样例文件包含十类各一条违规、一条正常、一条边界，共 30 条，均为人工合成。初测严格集合准确率 28/30，发现 1 条内部财务细节漏报。整改后为 **29/30（96.67%）**，十个目标违规均检出，二十条正常/边界样例全部无命中。剩余一条严格集合差异为姓名加手机号同时命中 `text_id` 与 `struct_id`，原单标签仅为 `text_id`。该差异保留在结果与复核清单中。

历史 2172 条中剩余 83 行需要由标注负责人补充多标签判定，逐项决定额外命中是否构成真实误报。当前材料保留这 88 个额外命中及其对指标的影响。冻结集的历史成绩仍使用各自原有材料，本次修改后的开发回归成绩独立列示。
