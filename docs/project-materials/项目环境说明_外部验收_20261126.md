## 1. 环境范围与版本基线

项目由 OneCity 业务入口、DeerFlow 智能体后端、独立 DeerFlow 网页、工具沙箱、合规检测及场景技能组成。场景技能涉及政策法规、程序代码、网络流量、道路交通、手机网络、时空轨迹、视频监控、遥感和街景等数据分析。

| 对象 | 当前情况 | 验收时的含义 |
| --- | --- | --- |
| 本次整理的代码仓库 | 分支 `integrate/street-onecity-20261125`；HEAD `bfbd7aa24d0c` | 包含统一后的 OneCity 源码和街景服务；HEAD 不代表线上所有容器的代码版本 |
| OneCity 集成入口 | 宿主机 HTTP `8086` | 已接入专用 DeerFlow 多用户后端，是核验身份、会话和文件隔离的入口 |
| OneCity 专用后端 | `onecity-deerflow-gateway`、`onecity-deerflow-langgraph` | 使用 2026-11-12 私有发布包中的只读 backend 快照，独立数据目录 |
| 独立 DeerFlow 网页 | 宿主机 HTTP `3328`；`gaozhuohui-deer-flow-*` 容器组 | 源码挂载自另一工作区 `imiss-deer-flow-integrate-final`，与本仓库及专用快照分别管理 |

## 3. 当前部署拓扑与端口

```text
浏览器 → OneCity Nginx（宿主 8086 → 容器 80）
           ├─ OneCity Flask API（容器内 7606）→ MySQL（3306）
           └─ Coordinator / IAM bridge（容器内 7010）
                    → 专用 Gateway（3330）→ 专用 LangGraph（3329）
                         → 大模型 / 检索 / 合规 / 场景技能 / AIO 沙箱

浏览器 → 独立 DeerFlow Nginx（宿主 3328）
           ├─ Next.js 前端（3331）
           ├─ 独立 Gateway（3330）
           └─ 独立 LangGraph（3329）
```

两套后端的容器内端口可以相同；OneCity 专用 Gateway/LangGraph 没有发布宿主端口，通过 `onecityagent-net` 私网通信。

| 检测位置 | InputGate / ContextGate / OutputGate 均启用，失败策略 closed |
| 预算 / 上下文 | 每闸 15000ms；Context 最多 32 单元；预算不能抢占正在运行的单个检测器 |
| 输出检查方式 | stream_retract，每 200 字符增量扫描；不属于全量缓存后一次输出 |
| 场景来源 | trusted_upstream；未解析为 `_unknown` |

十类检测配置使用结构标识、位置、凭证、违法/政治 V4、自由文本标识、商业秘密等规则及模型复核，并以 TF-IDF+kNN 覆盖第 8/9/10 类。其效果需依据冻结样本和验收指标评估，不能由“检测器已配置”推定准确率达标。
